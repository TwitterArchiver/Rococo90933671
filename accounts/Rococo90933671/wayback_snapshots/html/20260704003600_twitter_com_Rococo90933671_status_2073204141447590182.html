所有的焦虑都来源于对生存的焦虑。一个人如果潜意识里认为自己生存概率越高，他就越不焦虑；他自认为自己的生存概率越低，他就越容易焦虑。

比如社交，如果他没有很多朋友，他可能会焦虑。现代大多数人都非常恐惧孤独，很多人对自己一个人而感到羞耻。这是因为，人在远古时期野外生存，面对猛兽，必须结伙抱团才能生存，被集体排斥意味着死亡。因此，根据进化论，具有爱结伙抱团基因的人类更容易存活下来，现代人依然具备强烈的社交焦虑基因代码。由此可以得出，社交焦虑其实是生存焦虑——因为没有队友，容易被猛兽吃掉，所以没有队友就大大降低了生存概率。人们不是怕没有朋友本身，而是惧怕没有朋友时，面对未来的未知情况，无法自己一人处理，从而降低了自己的生存概率。

重要的话说三遍：人真正怕的是自己被降低了生存概率！人并不怕没工作、没朋友、没钱，人真正怕的是被降低了生存概率！这些事物一切都指向被降低了生存概率！从远古时代到现在，只有拼命提高生存概率的人才能存活下去，不在乎生存概率降低的人都已经灭绝了。因此，活到现在的人，基因里都是一旦监测到生存概率降低就抓狂、要疯狂提高生存概率的偏执狂。

这个生存概率是人主观感知的概率，而不是真实理性的客观生存概率。
社交焦虑 = 被排斥 = 远古时期独自面对剑齿虎 = 死亡。
工作焦虑 = 失去收入 = 无法获取食物与庇护所 = 死亡。
健康焦虑 = 身体机能受损 = 无法逃脱危险或无法战胜猛兽 = 死亡。
社会评价焦虑 = 声誉受损 = 被部落抛弃 = 死亡。

所有焦虑的根源，都是原始脑对“生存概率”下降而拉响的警报。现代生活中，这个原始脑常把“生活姿态的改变”（如失去面子、遭受拒绝、丢掉工作、独处）严重错误地计算为“生存本身的危机”。这并不是原始脑糟糕，反而是原始脑对人类恪尽职守的保护。人类之所以能从万千年前远古时期凶残恶劣的环境中存活至今，都离不开原始脑百无一漏的提高警觉。一次的放松警惕导致的后果就是死亡。原始脑拉响的警报机制早已自动化，非一般理性能克制，如同条件反射
